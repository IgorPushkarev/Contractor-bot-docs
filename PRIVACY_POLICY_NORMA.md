## 4. ЗБІР ТА ЗБЕРІГАННЯ ДАНИХ

4.1. Для роботи Бота, зокрема для дотримання денного ліміту звернень та ведення статистики, Бот **зберігає технічний мінімум даних**:

- **Ідентифікатор Telegram** (chat_id / user_id) — для надсилання відповіді та обліку
- **Ім'я користувача Telegram** (username, за наявності) — для ідентифікації в адміністративній панелі
- **Дату першого звернення** та **лічильник запитів** — для дотримання денного ліміту (5 звернень на добу) та запобігання зловживанням
- **Коротку історію звернень** (технічний журнал: час, тривалість, фрагмент запиту до 80 символів) — для статистики та покращення роботи Бота

4.2. Бот **НЕ збирає та НЕ зберігає**:

- Паролі, платіжні дані, документи, що посвідчують особу
- Повні тексти приватного листування поза Ботом
- Cookies чи ідентифікатори відстеження в мережі

4.3. **Обсяг зберігання обмежений:** технічний журнал звернень зберігається у межах останніх записів (з автоматичним обмеженням обсягу) і не накопичується безмежно.

4.4. **Мінімізація даних (GDPR ст. 5(1)(c)):** Бот обробляє лише той мінімум даних, який технічно необхідний для надання послуги та обліку.
